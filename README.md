# NoSQL Document Database Demo

A simple demo of CRUD operations (Create, Read, Update, Delete)
on a document database using the Astra DB Data API (Python).

Note: the Document API shown in the tutorial video has reached
end-of-life, so this project uses its replacement, the Data API.

## How to run
1. Install the libraries: pip install astrapy python-dotenv
2. Copy .env.example to .env and fill in your own Astra DB endpoint and token
3. Run: python main.py
